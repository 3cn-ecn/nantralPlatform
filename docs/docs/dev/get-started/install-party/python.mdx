## Install uv

`uv` will be our python version and dependency manager, to handle dependencies of the project.

Here is the usual way to install uv with an automated script.
Visit the [official installation page](https://docs.astral.sh/uv/getting-started/installation/)
for other installation methods.

<Tabs groupId="os">
    <TabItem value="win" label="Windows">
        Run this script in a powershell window:
        ```powershell
        powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
        ```
    </TabItem>
    <TabItem value="mac-lin" label="MacOS/Linux">
        Run this script in a terminal:
        ```bash
        curl -LsSf https://astral.sh/uv/install.sh | sh
        ```

        Or, if you prefer wget:
        ```bash
        wget -qO- https://astral.sh/uv/install.sh | sh
        ```
    </TabItem>

</Tabs>

Check that `uv` is correctly installed with

```bash
uv --version
```

## Install Python and dependencies

`uv` is very easy to use. It will automatically install the right python
version for you and then retrieve all the dependencies with their correct
versions. You need to run the following command and watch the magic.

```bash
cd backend  # ensure that we are in the correct working directory
uv sync --dev
```

That's it! You finished to install python, congratulations 🥳
